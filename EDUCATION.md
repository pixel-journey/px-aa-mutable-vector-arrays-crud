# Education — vector attributes on mutables

AtomicAssets supports vector attribute types. This lab teaches push, erase, clear, kind locking, and **sibling keys** so a vector edit never wipes another field.

## Outcomes

1. Show erase shifts later indices.
2. Show clear keeps the key and kind.
3. Show kind mismatch does not mutate the map.
4. Show MAX_VEC_LEN is a lab cap, not necessarily the chain max.
